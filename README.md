# C++ 基础自测

为 Hello, Algorithm! 算法训练营准备的 10 题分组自测。双击 `index.html` 就能在浏览器中使用，也可直接托管到 GitHub Pages。无需安装、账号、服务器或外部资源，手机与电脑都能答题。

题目仅覆盖分支、循环、逻辑运算符 `&&`、`||`、`!`、简单递归，以及 vector、string、stack、queue 的入门用法。全部单选，每题最高 1 分，部分正确 0.5 分、错误或不会 0 分。逻辑判断题有两个输出，判断对一个计 0.5 分。点击选项后自动进入下一题，最后一题需点击提交；提交前可以回看和修改答案。提交后显示成绩、分组建议和答案解析。答题页不显示知识点标签。

题目分布：分支循环 1 题，逻辑判断 2 题，递归 1 题，vector 2 题，string 2 题，stack 和 queue 各 1 题。每题最高 1 分，满分 10 分。递归题替换了原来重复考循环概念的题目。

## 分组规则

| 分数 | 建议 | 结果文案 |
| --- | --- | --- |
| 0–6 | 推荐零基础组 | 我们推荐您报名 0 基础组。 |
| 6.5–8.5 | 可以挑战进阶组 | 您的基础有些漏洞，但是可以挑战进阶组！ |
| 9–10 | 推荐进阶组 | 您的基础没有任何问题，请您选择进阶组大杀四方吧！ |

这是入门用法自测，结果用于选择题单难度。它不会上传或集中收集成绩。刷新或关闭页面会清空本次答案。

## 放到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `stl-quiz`。如使用 GitHub Free，选择公开仓库。
2. 把本文件夹里的 `index.html`、`.nojekyll` 和 `README.md` 上传到仓库根目录并提交到 `main` 分支。不要把整个文件夹作为第二层目录上传。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 和 **/(root)**，点击 **Save**。等待 GitHub 完成发布后，用 Pages 显示的访问链接分享给同学。

项目仓库的地址通常是 `https://你的用户名.github.io/stl-quiz/`；若仓库名称是 `你的用户名.github.io`，页面会在根域名发布。这里是地址格式示例，并非已发布的网址。

## 修改题目或文案

用文本编辑器打开 `index.html`：

- `QUESTIONS` 是题库，每题 4 个 A–D 选项，第 5 个“还没学会”由页面自动添加。
- `score` 只使用 `0`、`0.5` 和 `1`；每题恰好一项为 `1`。
- `explanation` 是提交后显示的解析，涉及半对选项时同步修改说明。
- `GROUP_RULES` 控制分组门槛，`getGroup` 控制三段结果文案。修改门槛时同步修改本说明中的分数区间。

保留 10 题可直接修改内容。调整题数时，还需同步页面上写死的总题数、总分和分组区间。

## 使用边界

这是自测用纯前端页面，题库和计分规则在源文件中可见，适合诚实自评，不适合防作弊考试。不包含报名表、排名或跨设备成绩统计。
